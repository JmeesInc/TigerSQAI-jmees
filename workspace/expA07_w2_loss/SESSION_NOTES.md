# expA07_w2_loss

**expA06 + 損失側クラス重みの二乗化**（ユーザー指示 2026-09-06）。
公式 metric の重み 3/2/1 を、**学習損失でのみ** 9/4/1 に強調する。

## 変更内容

- `loss.weight_power: 2.0` を config に追加。`train.py` で `w ** pw` を
  fine / coarse / f2c の 3 つの Dice loss すべてに適用
- **監視メトリクス (val の weighted Dice) と公式評価は従来の 3/2/1 のまま** → 比較の一貫性を維持
- 他は expA06 と完全同一（MaxViT-Base tf_512 + dual Unet++ + 強aug + f2c loss, fold v1）

## 動機

- per-class 分析で **w=3 の小構造（Lymph_Node 0.32 / R_Vagal 0.37 / R_Inf_Pul_Lig 0.75）**が
  依然としてスコアの主要ボトルネック
- 公式 metric は加重平均なので、損失側で重みを強調すれば加重指標が改善する可能性

## プロトコル

- **無条件 5-fold**（ユーザー指示でゲート撤廃）→ OOF 全量公式評価 → expA06 と比較
- 比較対象: expA06 = T1 Dice 0.6663 / HD 0.2646, T2 Dice 0.6530 / HD 0.2574（監視 val 平均 0.6562）

## 経過（fold0）

| epoch | val score | expA06 同 epoch |
|-------|-----------|----------------|
| 10 | 0.5668 | 0.5405 (+0.026) |
| 20 | 0.6340 | 0.6166 (+0.017) |
| 30 | 0.6425 | 0.6460 (−0.004) |
| 40 | 0.6357 | — |
| 50 | 0.6404 | — |

- 序盤は明確にリードするが中盤以降で拮抗
- **fold0 完走: best val/score 0.6520**（expA06 f0 0.6575 に **−0.0055**）
  → 序盤の収束は速いが最終到達点はやや下。fold1〜4 の結果と OOF 公式評価で最終判断
  （公式指標は加重平均なので、監視 val の僅差が公式 Dice/HD でどう出るかは別途要確認）

## 結果

| fold | expA07 (w²) | expA06 (参照) | 差 |
|------|------------|--------------|-----|
| 0 | 0.6520 | 0.6575 | −0.0055 |
| 1 | 0.6338 | 0.6474 | −0.0136 |
| 2 | 0.6120 | 0.6435 | −0.0315 |
| 3-4 | **打ち切り（2026-09-06 ユーザー判断）** | | |

- **3 fold 連続で下回り差が拡大（−0.006 → −0.014 → −0.032）→ 打ち切り・不採用**
- 解釈: 損失側で w=3 を 9 倍に強めると頻出クラス（背景・脂肪・肺）の学習が相対的に薄くなり、
  小構造の改善分を上回って全体が崩れる。**metric の重みと損失の重みは一致させるのが良い**
- 序盤の収束だけは速い（ep10-20 で +0.02〜0.03）ので warmup 的用途の余地は残る
