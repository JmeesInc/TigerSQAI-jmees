# expA18_ep40

**expA11（v2 基準線）と完全同一レシピで epochs 60 → 40 のみ変更**。

## 動機

学習済み 12 fold すべてで **best epoch が 32〜56、かつ「best > 最終10ep平均」** が例外なく成立していた
（差 +0.003〜+0.018）。cosine で LR が 0 に向かう終盤に劣化するので、LR 由来ではなく過学習。
expA12（checkpoint averaging）が失敗した理由もこれで、tail を平均する限り差は埋まらない。

→ 40 epoch で閉じれば **同等以上のスコアを 2/3 の学習時間で**得られる可能性がある。
残り日数で回せる実験本数が 1.5 倍になるので、当たれば効果は大きい。

## プロトコル

- 比較対象: expA11 fold0 = 0.6569（同一 config・同一 fold）
- run 間分散は 0.0024（expA11 fold0 vs expA12 fold0 の同一設定再走で実測）
  → 0.6545 を下回らなければ「短縮しても劣化なし」と判定できる
