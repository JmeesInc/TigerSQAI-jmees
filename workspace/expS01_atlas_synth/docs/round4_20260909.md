# Round 4: 解剖のみ正規化・壁側胸膜・登録のFOV除外

2026-09-09のユーザー最終決定を採用。GitHubは実装開始時 `be3b4a6` が最新で、Linux結果は今回共有された集計を根拠とする。実画像・実マスク・実CSVにはアクセスしていない。

## 有効な基準

`assets/reference_anatomy_only.yaml` は実528枚の共有された最終表をそのまま保存する。面積は各フレーム内のID 3–30画素数で正規化した比率の平均。0/1/2は出現率・面積誤差・クラス数から除外する。背景率だけは全画面に対する独立診断。解剖0画素のフレームは明示してバンクを止める。過去の基準ファイルは履歴として残るが既定CLIからは使わない。

器具は `configs/dissection.yaml: instruments.enabled: false`。Otherは生成しない。器具の古い実装は再現用に残すが既定では呼び出しが即座に空配列を返し、器具衝突棄却も発生しない。血液24と剥離面25は維持。円形視野マスクは導入しない。学習側cutoutアセットにはアクセス・取得していない。

## 壁側胸膜

同一公開Z-Anatomyアセットの左右第3–10肋骨を輸出し、肋骨点群の凸包を内側へoffsetした閉じた表面をPleura(10)として追加する。既存胸郭の加工であり、新しい解剖アトラスの創作ではない。肋間の空白を橋渡しし、ポート位置には局所的な筒状の開口を設ける。元の肋骨コンテキスト面も胸壁被覆のラベル10とする。画素の0→10置換は行わず、すべてObject Index pass_indexで深度と同時に描画する。

これは**暫定の肋骨包絡面**であり、実際の壁側胸膜の形状・横隔膜・胸膜頂を精密再構成したものではない。凸包の上下閉鎖面にも近似がある。`parietal_pleura` のinset・mesh edge・port radius/tunnel lengthは設定可能。provenanceに手法と暫定性を記録する。元の胸郭・ポート・シャフトの衝突検査は維持する。

追加メッシュのライセンスは既存Z-Anatomy由来のCC-BY-SA-4.0。出典 https://github.com/Z-Anatomy/Models-of-human-anatomy 。商用利用可、改変メッシュを配布する場合は表示・変更表示・同一ライセンス等の条件を継承。既存のアセット来歴を保持し、新規外部アセットは追加していない。

## 登録

`configs/registration.yaml: real_background_policy: ignore`。weighted IoUは実マスクのclass 0画素を評価領域から除外する。画像の明るさ・円の推定は使わない。実の解剖画素の位置で合成が0なら誤りとして計上する。除外前景クラスの未知遮蔽扱いも維持する。kNN記述子は粗検索であり、この変更は再スコアの画素領域に適用する。実マスクによる採択率やconfidenceの検証はLinux側で行う。

## 評価とバンク

```bash
python -m render.generate --frames 128 --output outputs/round4_128 \
  --resolution 256 144 --workers 8 --device CUDA \
  --blender /path/to/blender --allow-provisional
python -m render.audit_outputs outputs/round4_128
python -m render.calibration_report outputs/round4_128 --output outputs/round4_128/report
```

新しいゲートschema_version=2はRound 3の合格レポートを拒否する。保守的な判定方針として、出現率・面積の総誤差が新baselineを下回り、Pleura/Lung/クラス数中央値も目標までの差が縮小し、背景中央値が0–2%に入ることを全て要求する。p10/p90も常時表示するが独立の合否条件にはしていない。これは目標表をコードに落とす際の厳格な運用解釈であり、主催者の評価規則ではない。128枚以上、完了バッチ、12/8/9出現、設定一致も必要。不合格ならバンクを生成しない。

IPV保護の減算対象は心膜proxyだけであり、元のIPVメッシュは不変。IPV面積不足から「静脈メッシュが削られた」とは結論しない。余白・遮蔽・視点による変化を区別する必要がある。


## カメラと未採用試験

壁側胸膜を追加したうえで旧占有率0.65を使うと、8枚試験でPleura面積49.36%になった。既定の局所開口占有率priorを mean1.10 / sd0.15 / min0.8 / max1.4へ変更した。1を超える値は局所開口の直径が画像短辺より大きい近接視野を意味する。投影輪郭の実測値ではなく既存のface-on近似であり、撮影距離20–120mmと硬性鏡幾何・衝突制約を満たさない候補は引き続き棄却する。

下縦隔anchor重み0.45、肺の虚脱を弱くするscale[0.70,0.85,0.95]、心膜margin0.5mm/IPV clearance8mmの組合せも32枚で試験したが、出現率誤差753.18pp・面積誤差78.76ppとなり、右下肺靭帯が未出現だった。**未採用**。複数変更を組み合わせた探索なので個別因子の効果は断定しない。`*_round4_lung_trial.yaml`に試験設定を残す。最終設定の肺虚脱・心膜保護幅はRound 3の値へ戻した。`*_round4_wall.yaml`は最終設定を保存した比較用の複製。
