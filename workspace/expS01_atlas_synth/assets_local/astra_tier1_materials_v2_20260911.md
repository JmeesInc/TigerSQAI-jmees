# Tier1 材質の改訂依頼（2026-09-11）— 色度・血管柄・クラス別テクスチャ

## Linux 実機での確認結果（先に共有）

`--emit-rgb` は Linux/EEVEE で動作しました。21 テスト・audit_outputs・alignment の
`edge_evidence_pass` すべて通過。1024×576 / 2 worker / 4 枚で 106 秒。
**選択肢 1（`--rerender-triplet` で EEVEE の RGB/label/depth を揃える）を採用**します。

ただし生成画像を目視した結果、**幾何・陰影・遠近は良好だが色域が術野から外れています**。
全体に灰〜くすんだ緑褐色で、内視鏡画像特有の「赤〜ピンク寄りの高彩度」になっていません。
doc に「base_hue は例示色」と明記されているとおりで、これは仕様どおりの挙動です。

前回「色より texture が大事、色は画角と光で変わる」とお伝えしましたが、**指定の仕方が不適切でした**。
正しくは **輝度で正規化した色度（chromaticity）** を使うべきで、これは照明の「強さ」に不変です。
測り直したので差し替えてください。

**読み取り方**:
- 全解剖クラスが **r 色度 0.46〜0.64 = 赤優勢**。現在の灰緑〜カーキとは方向が違う
- **彩度 0.44〜0.75 と高い**。現状の低彩度は実データと乖離
- 器具(1) だけが r 0.402 / 彩度 0.261 と**無彩色寄り** ＝ 金属。ここは正しく区別すること
- 色温度には依存する値なので、**絶対 RGB ではなく「色度 + 彩度」を base albedo の指定に使う**こと
- 光源は既に逆二乗減衰なので、明暗はそちらが作る。albedo は色味だけを担う

### 依頼
- **分岐する血管網のプロシージャルテクスチャ**を追加し、上表の強度でクラスごとに重み付けする
  - 実装は Voronoi の稜線 / ノイズの ridged 変換など、**細い分岐線が出る**もの
  - 色は base albedo に対して **赤側へ寄せる**（r 色度を +0.05〜0.10 程度）
  - **太さに階層**を持たせる（太い幹 + 細い枝）。単一スケールだと網に見えません
- **器具(1) と肺(18) には血管柄を出さない**（実測でも最低値）

## 3. クラス別のテクスチャ種別（現在は全クラス等方ノイズ）

|クラス|実データの見え方|推奨テクスチャ|
|---|---|---|
|20/7 Fatty tissue|**小葉構造**（脂肪細胞の塊が房状）|Voronoi セル、細胞サイズ 1〜3mm|
|25 Resection area|粗く不規則、焼灼痕|高周波ノイズ + 不規則な明暗斑|
|10 Pleura|**平滑で光沢**、下の構造が透ける|低周波のみ + 高 specular。半透明感|
|24 Pool of blood|液面、強い鏡面|平滑 + 非常に高い specular + 最高彩度|
|15/16/12/17 血管|**管の長軸方向に走る微細な筋**|軸方向に引き伸ばしたノイズ|
|3/4/5 気管・気管支|**軟骨輪の横縞**|軸に直交する周期的な畝|
|19 Lymph node|やや粗い粒状|中スケール Voronoi|

※ 前回「異方性 1.16〜1.42 でほぼ等方」と伝えましたが、これは**クラス領域全体の勾配エネルギー比**で、
管状構造の**局所的な軸方向性**は捉えていません。血管と気管支には方向性テクスチャを入れてください。
前回の「等方ノイズでよい」は撤回します。

## 4. 優先順位

締切が近いため、効果の大きい順に:
1. **色度の修正**（表のとおり赤優勢・高彩度へ）— 最も影響が大きく、実装は最も軽い
2. **血管網テクスチャ**— 漿膜面の見え方を決定づける
3. 脂肪の Voronoi 小葉構造
4. 管状構造の軸方向テクスチャ、気管支の輪状構造

1 と 2 だけでも大きく変わるはずです。3・4 は余力があれば。

## 5. 再出力について
このパラメータで確定したら、こちら（Linux）で `--rerender-triplet` を使って
既存 2000 フレームのカメラ姿勢から EEVEE で RGB/label/depth を揃えて再出力します。
実測 26.6 秒/枚（初期化込み 4 枚 106 秒）なので、並列数を上げれば現実的な時間で回せます。
